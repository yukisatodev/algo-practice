# algo-practice

アルゴリズム問題を解いて積み上げていく、学習用のリポジトリです。
ポートフォリオの「制作物」とは別に、日々の学習記録として運用しています。

## 方針

- 1問1ファイルで、標準入力から読み取り・標準出力に書き出す形式（paizaと同じスタイル）に統一
- 各ファイルの冒頭に、問題の概要と自分なりの解法メモを残す
- 解けなくて詰まった問題も、`- 未完了` として残しておく（後で見返すため）

## 構成

```
algo-practice/
  python/
    001_fizzbuzz.py
    002_two_sum.py
    003_palindrome_check.py
    ...
```

ファイル名は `連番_問題名.py` で統一しています。

## 進捗

| # | 問題 | 難易度目安 | 状態 |
|---|---|---|---|
| 001 | FizzBuzz | easy | ✅ |
| 002 | Two Sum（2つの和） | easy | ✅ |
| 003 | 回文判定 | easy | ✅ |

## 新しい問題を追加するときのテンプレート

```python
"""
問題: (問題の概要を1〜2行で)
入力: (入力の形式)
出力: (出力の形式)
"""

def solve():
    # 標準入力を読む
    ...
    # 処理
    ...
    # 標準出力に書く
    print(...)


if __name__ == "__main__":
    solve()
```

## ローカルで実行する

```bash
python3 python/001_fizzbuzz.py
```

標準入力が必要な問題は、以下のようにパイプで渡すか、実行後にキーボードから入力してください。

```bash
echo "5" | python3 python/002_two_sum.py
```
